# Copfire Studio

**点燃创意，构建世界。**  
*Ignite ideas. Build worlds.*

Copfire Studio 是一家由热情驱动的小型工作室，专注于 Minecraft 服务端插件与 Web 全栈开发。我们因共同兴趣而协作，致力于将创意转化为可运行、可使用、可持续维护的作品。

*Copfire Studio is a small, passion-driven studio specializing in Minecraft server plugins and full-stack web development. We collaborate through shared interests and are committed to turning ideas into runnable, usable, and maintainable projects.*

我们不以短期回报为导向，更重视长期投入与持续打磨，并乐于通过开源与分享，与社区共同成长。

*We are not oriented toward short-term returns; rather, we value long-term commitment and continuous refinement, and we are glad to grow together with the community through open source and sharing.*

**以火为名，以码筑界。**  
*Code with fire. Build with care.*
